{# Link attributes for a file attachment: href to /files// (see components/download-url). Without download: PDFs and images open in a new tab as a preview (the download page serves them inline); every other type is saved as an attachment under its original name. With download=true: the link always saves the file (?download=1). data-rl-file ("preview" / "download") lets the Matomo snippet in the layout record the two as separate events. Usage: #} {%- if file -%} {%- set rl_previewable = file.getExtension()|lower in ['pdf', 'png', 'jpg', 'jpeg', 'gif', 'webp'] or file.content_type == 'application/pdf' -%} href="{{ partial('components/download-url', { file: file, download: download }) }}" {%- if download or not rl_previewable %} download data-rl-file="download"{% else %} target="_blank" rel="noopener" data-rl-file="preview"{% endif %} {%- endif -%}
